# Syntra B2B

Portal demonstrativo de compras empresariais com catálogo em volume, tabelas de preço, cotações, aprovação de pedidos e área administrativa.

## Arquitetura

- Aplicação web: Next.js preparada para deploy na Netlify.
- API: Cloudflare Workers.
- Banco relacional: Cloudflare D1.
- Os dados e fluxos são demonstrativos. Não use dados empresariais reais.
